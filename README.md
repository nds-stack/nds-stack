### 🇮🇩 Indonesia SDK Collection

Tools for Indonesian payment systems and banking APIs.

| Module | Description |
|--------|-------------|
| [bca-merchant-sdk](https://github.com/nds-stack/bca-merchant-sdk) | Unofficial BCA Merchant API — QRIS, encrypted login, transaction history, auto token refresh |
| [ibank-bca-sdk](https://github.com/nds-stack/ibank-bca-sdk) | Unofficial iBank BCA — login, balance check, transaction mutations via pure HTTP |
| [qris-utils](https://github.com/nds-stack/qris-utils) | QRIS utility — decode, parse, static-to-dynamic, validate payment codes |
